# AI Troubleshooting - v0.5
AI was used as a development assistant throughout v0.5.

Assistance included:
- Reviewing program structure and suggesting refactoring opportunities.
- Explaining Python concepts including nested dictionaries, lambda functions and custom sorting.
- Discussing feature ideas and report layout from a security analyst perspective.
- Assisting with debugging logic and program flow.

All implementation, testing, debugging, integration and final code decisions were completed by the project author.
