# AI Assistance - Version 0.3

## Purpose

Artificial intelligence was used throughout this version as a learning and troubleshooting assistant rather than a code generator. The goal was to better understand unfamiliar Python concepts while maintaining ownership of the implementation.

---

## How AI Was Used

AI was primarily used to:

- Explain Python concepts such as dictionaries, loops, functions and regular expressions.
- Help diagnose syntax, indentation and logic errors during development.
- Break larger programming problems into smaller, manageable steps.
- Suggest improvements to output formatting and code readability.
- Review completed code and provide feedback on maintainability and structure.

Rather than requesting complete solutions, I frequently asked for hints or explanations so I could implement the logic myself.

---

## My Contribution

The overall design, implementation and testing of Version 0.3 remained my responsibility. This included:

- Designing the parser workflow.
- Creating and integrating the `extract_ip()` function.
- Implementing the IP occurrence counting logic.
- Testing the parser against the authentication log.
- Improving the console output.
- Writing comments and project documentation.
- Debugging and refining the implementation through multiple iterations.

---

## Reflection

Using AI significantly reduced the time spent researching syntax and debugging individual issues while allowing me to focus on understanding the underlying concepts. Whenever AI introduced a new technique, I worked through the implementation step by step before incorporating it into the project.

The objective throughout development was to use AI as a tutor and troubleshooting assistant rather than as a replacement for learning or software development.
