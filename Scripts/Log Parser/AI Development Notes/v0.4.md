# AI Troubleshooting – v0.4

## Problem 1

Initially attempted to associate Disconnecting events with source IP addresses.

Issue:

Disconnecting log entries within the sample Auth.log did not contain IPv4 addresses.

Resolution:

Disconnecting events remain part of the overall SSH Event Summary but are no longer correlated with individual source IP addresses.

---

## Problem 2

Repeated IP tracking was temporarily removed while implementing event correlation.

Resolution:

Reintroduced the ip_counts dictionary so repeated IP detection and per-IP event tracking could operate independently.

---

## Problem 3

The parser originally attempted to access ips[0] before verifying an IP address had been extracted.

Resolution:

Moved IP processing inside existing validation blocks to avoid potential indexing errors.

---

## Problem 4

The initial IP Activity Report displayed every detected source IP, including insignificant events.

Resolution:

Added filtering so only source IPs responsible for multiple failed password attempts are displayed.
