v0.6 Development Notes

The main objective of v0.6 was to improve the structure and usability of the log parser while introducing structured export functionality.

Development focused on refactoring the existing parser into separate functions. Log processing was moved into a dedicated process_log() function, while source IP risk classification was separated into an analyse_risk() function. This improved separation of responsibilities and made the code easier to maintain.

Configurable thresholds were introduced for risk classification and high-frequency IP detection. Risk thresholds and event-frequency thresholds can now be modified through configuration variables rather than being hardcoded throughout the analysis logic.

CSV export functionality was added to allow analysed IP activity to be exported into a spreadsheet-compatible format containing the source IP, failed password count, error count and risk classification.

JSON export functionality was also added to preserve the structured IP event data in a format that can be consumed by other programs or tools.

The existing terminal reporting was retained and tested alongside the new functionality to ensure the refactoring did not break the existing analysis.

v0.6 also established the foundation for eventually making the parser more universal by reducing reliance on hardcoded analysis logic and separating processing, analysis and output responsibilities.
