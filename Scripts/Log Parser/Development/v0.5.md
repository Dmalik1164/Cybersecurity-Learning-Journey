# Version: v0.5 - Threat Prioritisation & Report Refactoring

# Objectives
- Introduce per-IP risk assessment.
- Refactor the reporting pipeline for improved readability.
- Reduce low-value output.
- Prioritise suspicious activity for faster analysis.

# Completed
- Refactored analysis and reporting into separate processing stages.
- Added HIGH / MEDIUM / LOW risk classification based on failed password thresholds.
- Added Threat Assessment summary section.
- Stored risk classification within each IP event dictionary.
- Introduced overall risk counters.
- Filtered High Frequency Source IPs using a 10+ event threshold.
- Sorted High Frequency Source IPs by event count (highest first).
- Sorted IP Activity Report by failed password count.
- Improved report layout and added "Analysis Complete" footer.

# Outcome
The parser now produces a structured analyst-focused report that prioritises suspicious activity while reducing unnecessary output.
