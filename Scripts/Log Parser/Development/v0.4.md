# Development Log – v0.4

## Objective

Expand the SSH authentication log parser by correlating extracted source IP addresses with authentication events, producing a clearer and more informative security report.

---

## Features Added

### SSH Event Correlation

Introduced an `ip_events` dictionary to associate each extracted source IP with the SSH authentication events it generated.

Each source IP now tracks:

- Failed password attempts
- Authentication errors

---

### IP Activity Report

Implemented a new IP Activity Report displaying event information for each source IP.

Example output:

Source IP: 201.178.81.113

Failed Passwords: 32
Errors: 1

---

### Improved Output Filtering

Added filtering to remove low-value results.

Only source IPs responsible for more than one failed password attempt are displayed within the IP Activity Report.

This improves readability by reducing noise from isolated authentication failures.

---

### Repeated IP Detection

Reintroduced repeated IP address tracking alongside the new event correlation logic.

Repeated source IP addresses continue to be displayed separately from the detailed activity report.

---

### Code Improvements

- Improved organisation of parser logic.
- Added defensive handling when extracted IP lists are empty.
- Expanded inline documentation throughout the parser.
